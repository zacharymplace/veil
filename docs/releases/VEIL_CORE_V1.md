# Veil Core v1

## Status

Released locally.

## Included

- Tauri desktop shell
- React/TypeScript UI
- Rust command layer
- SQLite persistence
- Audit screen
- Database verification
- JSON import/export
- Backup export to file
- Encrypted export/import prototype
- Veil Core architecture
- Policy smoke test
- SQLite contract test
- Core diagnostics test

## Boundary

Veil remains a local-first privacy browser and vault prototype. It does not host, scrape, download, recommend, or distribute content.
