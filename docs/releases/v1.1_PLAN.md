# Veil v1.1 Plan

## Status

Planned. No feature work should begin until this plan is reviewed.

## Goal

Move Veil from a safe local prototype toward a real private browsing runtime without weakening the project boundaries.

## Candidate Scope

- Live WebView binding
- WebView permission callback integration
- WebView download callback integration
- Persisted permission registry
- Persisted download registry
- Argon2id passphrase derivation
- OS keychain evaluation
- SQLCipher evaluation

## Non-Goals

- No content hosting
- No scraping
- No media downloading
- No recommendation feed
- No cloud sync by default
- No production security claims until reviewed

## First Milestone

Bind the existing Browser Engine to a live WebView in the smallest possible way:

1. Open HTTPS URLs only
2. Block downloads
3. Prompt permissions
4. Audit every navigation
5. Preserve session isolation model

## Required Gates

- npm run check
- cargo check --manifest-path src-tauri/Cargo.toml
- Manual UI smoke test
- Updated release doc
